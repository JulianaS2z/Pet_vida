# Clínica Pet Vida

Banco de dados de uma clínica veterinária desenvolvido em MySQL.

## Estrutura do banco

- Tutores
- Animais
- Espécies
- Veterinários
- Consultas
- Pagamentos

## Funcionalidades

- Cadastro de tutores
- Cadastro de animais
- Controle de consultas
- Controle financeiro
- Relacionamentos com Foreign Keys
- Normalização utilizando tabela de espécies

## Tecnologias

- MySQL
- MySQL Workbench
- Git
- GitHub

## Como executar

1. Execute o arquivo `schema.sql`
2. Execute o arquivo `seed.sql`
